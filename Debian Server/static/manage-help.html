Help & Instructions

How to use the Lumina Hub and EduMesh app.

Getting Started
  • Connect — Join the EduMesh Wi-Fi hotspot broadcast by the Hub laptop. The captive portal opens automatically.
  • Install the app — On the welcome page, download the EduMesh APK and install it on your Android phone. Enable "Install from Unknown Sources" if prompted.
  • Register — Open the app, enter your name, and you are in. The Hub assigns you a permanent student ID.
  • Start learning — Browse textbooks, videos, and other resources. Download them to use offline.
For Teachers
  • Upload resources — Go to Content Manager, select a PDF or video, give it a title and subject, and click Upload. Resources are available to all students immediately.
  • Manage content — Filter by subject and grade to find resources. Click delete to remove any resource and its file.
  • View students — Go to Students to see all registered students, filter by grade, or search by name. Each card shows weekly study time, streak, and saved resources.
  • Detailed analytics — Click a student to see their full profile with study time breakdown and resource count.
  • Change your password — Go to Security to update your login credentials.
Student Tracking
  • Study time — The app tracks focused study sessions using the built-in timer. Total weekly minutes are synced to the Hub.
  • Streak — Consecutive days the student uses the app. Calculated on the phone and synced to the Hub.
  • Saved resources — Each time a student bookmarks or downloads a resource, the count is updated.
  • Privacy — Individual events (which PDF was opened, what was searched) stay on the student's phone and are never sent to the Hub.
Troubleshooting
  • App cannot connect — Ensure your phone is on the EduMesh Wi-Fi and the Hub laptop is powered on. Restart the app and wait a few seconds.
  • Forgot your password — Plug a keyboard into the Hub laptop and run sudo ./reset_admin.sh in a terminal. This resets the admin password to lumina2026.
  • App is slow — Close other apps, restart EduMesh, or clear app data from Android Settings and reinstall.
  • Hub storage is full — Delete unused resources from Content Manager. Check disk usage on the Home page. For advanced cleanup, run sudo ./setup_hub.sh.
Admin Tasks
  • Danger Zone — Reset all data, force admin password reset, set log retention, and view audit logs.
  • Settings — Toggle dark mode, view system info (Python version, database path, hostname).
  • Setup script — Run sudo ./setup_hub.sh to provision the hotspot, install dependencies, and configure the systemd service from scratch.
