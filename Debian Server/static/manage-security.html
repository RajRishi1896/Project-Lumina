You cannot disable the default admin while logged into it
Log in with a different admin or teacher account first, then disable the default admin from that account. This prevents accidental lockout.
Risks of disabling the default admin
  • The built-in admin account (username: admin) will be permanently blocked from login.
  • If all other teacher accounts are deleted or locked, the hub will be inaccessible.
  • Re-enabling requires physical access to the server or the Settings page from another admin account.
